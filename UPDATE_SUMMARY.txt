==========================================
DAY PLANNER - UPDATE SUMMARY
==========================================

✅ CHANGES COMPLETED

1. PORT CHANGED: 5000 → 6001
   - Access at: http://localhost:6001
   - Update your bookmarks!

2. NEW STORAGE SYSTEM
   - Events now stored in separate files (data/events/*.json)
   - Fast loading: Only loads events in current viewing window
   - Two index files for efficient queries:
     * events_index.json - ID to filename mapping
     * events_date_index.json - Date to event IDs mapping
   - Automatic migration from old single-file format
   - Scales to 100,000+ events efficiently

==========================================
HOW TO START
==========================================

1. Install dependencies (if not already done):
   pip install -r requirements.txt

2. Run the application:
   python app.py

3. Open browser:
   http://localhost:6001

4. If you have existing events.json:
   - It will be automatically migrated on startup
   - Original file backed up to events.json.backup
   - No action needed!

ROLLBACK (if needed)
==========================================

If you need to revert:

1. Stop server
2. Restore backup:
   rm -rf data/events/
   rm data/events_*.json
   mv data/events.json.backup data/events.json
3. Checkout previous git commit
4. Change port back to 5000 in app.py
